## 👾 关于本站

这个博客是一个 8-bit 像素风的小站:

- **框架**: [Astro](https://astro.build/) (静态生成,快到飞起)
- **主题**: [AstroPaper](https://github.com/satnaing/astro-paper) 深度换肤
- **像素风**: [NES.css](https://nostalgic-css.github.io/NES.css/) + 缝合像素体 + Press Start 2P
- **评论**: [giscus](https://giscus.app/zh-CN) (基于 GitHub Discussions)
- **部署**: Vercel

在这里,我记录技术、想法,偶尔也记录生活。

**Thanks for playing!** 🎮
